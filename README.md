# DUNE ENERGY GLOBAL

Public website: https://energydune.com/ (published from `gh-pages`).

## Daily SEO / GEO observations

[Open daily reports](https://github.com/tonygu0826/dune/actions/workflows/daily-search-report.yml).

The independent monitor runs at **09:00 America/Toronto** each day, including daylight-saving changes. GitHub may queue scheduled jobs, so this is a target time rather than guaranteed delivery to the minute. A manual run is also available. Each completed observation writes a Chinese Markdown report to the run's **Summary**, plus Markdown/JSON artifacts retained for 90 days. A cached previous snapshot supports comparisons; a missing baseline is stated explicitly. Critical technical findings mark the run failed after saving the report.

This workflow uses public GET requests only. It does not modify the site or send enquiries. It has no Google, Bing, mail or AI credentials, and does not publish private search statistics. The 20-query US/Canada English/French list is a measurement plan, not observed ranking data.

**Automatic delivery into a Codex conversation is not configured.** The workflow page and its report can be opened inside Codex's browser panel. A native Codex recurring task requires a scheduling capability that is not exposed to this cloud task; do not claim that the chat receives automatic daily messages.

See [monitoring setup and measurement limits](monitoring/README.md).
