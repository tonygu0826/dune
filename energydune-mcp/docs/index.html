Category search.
Structured enquiry drafts.

A public MCP interface for DUNE ENERGY GLOBAL INC. Retrieve published product categories, check enquiry fields and prepare an email draft for your own review.

Stateless Streamable HTTP · Authentication: none · English and French responses

This service provides category-level information. It has no SKU catalogue, price list, live stock, confirmed lead times or product-performance comparisons. Availability and specifications confirmed by quotation.

Brand names identify requested products, not authorised distribution. SINOPEC and Great Wall Lubricants are enquiry preferences; their inclusion does not establish product availability or affiliation.

What the tools add

Product terms and application filters retrieve relevant category records. Requirements are returned as structured field definitions, and draft inputs are validated before a summary and complete email body are returned. The tools do more than link to website pages, but they do not send an enquiry or complete a transaction.

Five tools

All tools accept optional lang: en or fr, default en. Records include English and French names; The email body is always English; lang controls localised metadata, category labels, summaries and messages. The live MCP tools/list response defines the authoritative schemas.

get_company_inforead

Returns the legal name, public contact, business segments, enquiry brands and scope/disclaimer notes. Optional input: lang.

{"lang":"en"}

list_product_categoriesread

Lists all six categories, or filters by segment: Automotive, Commercial, Industrial or Energy. Optional input: lang.

{"segment":"Commercial","lang":"en"}

search_productsread

Inputs: query, category, brand, application and optional lang. Supply a query or a filter. Matching is over category records, not individual products. A brand alone does not confirm any product. No match returns an empty result and enquiry guidance.

{"query":"ISO VG 46 hydraulic oil","brand":"SINOPEC","lang":"en"}

Each result carries the quotation note. This example identifies a category to discuss; it does not confirm a SKU, stock or suitability.

get_enquiry_requirementsread

Returns required and optional field definitions, permitted document requests and category-specific points to confirm. Optional inputs: category, lang.

{"category":"driveline","lang":"en"}

create_enquiry_draftwrite · draft only

Required strings: name, company, email and requirements.

Optional inputs: category, brand, product_reference, viscosity_or_grade, specification_or_oem, quantity_packaging, destination, documents_requested and lang. The current category default is pcmo. Use the canonical document array values TDS / PDS and SDS.

{
  "name": "Example Contact",
  "company": "Example Company",
  "email": "buyer@example.com",
  "requirements": "Please confirm suitable products and provide a quotation.",
  "category": "industrial",
  "viscosity_or_grade": "ISO VG 46",
  "documents_requested": ["TDS / PDS", "SDS"],
  "lang": "en"
}

Invalid or missing fields return machine-readable field errors. Successful output includes a structured summary, the complete email subject/body, a mailto link to info@energydune.com, and draft_only: true, sent: false, persisted: false. The live MCP schema may also reject invalid argument types before the handler runs.

If the fully encoded mailto URL would exceed 1,800 characters, the link contains only the recipient and subject. email.manual_copy_required is then true; the complete email.body remains available for manual copying.

Review the draft and send it yourself. This tool sends no email, saves no enquiry, creates no order and returns no submission or delivery confirmation. Document requests do not deliver a TDS/PDS or SDS automatically.

The example objects above are arguments to MCP tool calls, not separate REST endpoints. All contact details in examples are synthetic.

Access and limits

No product account, login or OAuth is required. Native rate limiting targets approximately 60 MCP POSTs per minute per client IP at each Cloudflare location. It is eventually consistent, not a strict global quota. Back off after HTTP 429; hosting limits also apply. Cloudflare plan eligibility and any usage charges must be confirmed with the account provider; free operation is not guaranteed.

Data handling

Tool arguments reach the hosted service as soon as a tool is called, including any name, email or other information supplied for a draft. The application processes them for the current response without an enquiry database or intentional request-body logs. Hosting infrastructure and Muse or another MCP client may retain logs, tool results or conversation history under their own policies. Read the separate MCP privacy notice before supplying personal or confidential information.
